# Rider–Waite–Smith tarot images

The 78 card images in this directory are the `color` set from
<https://github.com/yunruse/tarot>, released under CC0.

That project credits the original color scans to:
<https://luciellaes.itch.io/rider-waite-smith-tarot-cards-cc0>

Only the image files are used by 加点好运. No interpretation text from the
source repository is included.
