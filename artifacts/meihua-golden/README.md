# 梅花易数起卦规则与回归基线

更新时间：2026-07-16

本目录记录项目当前支持的起卦方式、固定口径与测试入口。普通用户页面不展示技术版本；这些内容仅供开发、复核和朋友验收。

## 固定基础

- 先天八卦数：乾一、兑二、离三、震四、巽五、坎六、艮七、坤八。
- 卦数除以 8，整除取 8；动爻除以 6，整除取 6。
- 六爻位置由下往上，动爻只翻转对应一爻。
- 互卦取本卦二至四爻为下互、三至五爻为上互。
- 动爻所在经卦为用，另一经卦为体。
- 时间统一使用 `Asia/Shanghai`，农历转换由 `lunar-typescript@1.8.6` 的独立 adapter 完成。

## 起卦方式

1. 当前时间：农历年支数 + 农历月数 + 农历日数取上卦；再加时支数取下卦和动爻。
2. 指定时间：与当前时间法完全相同，只是时间由用户明确选择。
3. 两数：第一数取上卦，第二数取下卦，两数之和取动爻。
4. 三数：第一数取上卦，第二数取下卦，第三数取动爻。
5. 文字字数：只接受 11 至 100 个汉字；标点、空格和非汉字不计。偶数平分，奇数少者为上、多者为下，总字数取动爻。不使用笔画和平仄。
6. 物数：可数物品数量取上卦，当前时支数取下卦，两数之和取动爻。
7. 声音：连续声音次数取上卦，次数加当前时支数取下卦并取动爻。
